附加内容：（详细信息查看CSDN链接） 烧录教程 ##（只写TLSR8359的设备）

###1.连接 准备工具：CH340G串口模块（普通款有TX，RX，3V3，GND就行，自动复位反而不如手动操作），杜邦线（母）若干

将杜邦线剪开，一头留铜丝，一头是母口 按照图片中的次序飞线： 飞线线序图（仓库里面image里面有） 其中除了NRST飞的杜邦线另一端留公口用于手动短接，其他的都留母口直接插到CH340G模块的插针上

###2.开始烧录

电脑端打开网页烧录工具，必须用Chrome或者Edge

https://atc1441.github.io/ATC_TLSR_Paper_UART_Flasher.html

可以用我的优化版工具： https://lightning1003.github.io/uart_flasher.html UI我重新进行了布局，界面更好看

把CH340G接到电脑上，随后在网页上点击“Open”，在弹出的窗口选择CH340G的COM号（不知道的可以右键开始-设备管理器-端口，里面看看CH340G device后面是COM多少），连接后点击“选择文件”，找到编译好的固件.bin文件

说明：固件.bin文件需要在你先运行github下载的zip包的Firmware文件夹里面的makeeit.exe编译获取，程序跑完后你就会在这个firmware文件夹里面找到ATC-Paper.bin了。如果本来firmware里面就有这个文件建议删掉后重新编译

选择.bin文件打开后： ##注意：烧录完成后必须拔掉其余接线只留下3V3和GND供电！不然会一直处在烧录模式

手动方案：拿起NRST上面的那根线，把线捅在GND插针上来短接NRST和GND，此时价签会停止串口检测通信强行初始化关机。松开的瞬间就点击“Unlock Flash”（解锁闪存），等待完成解锁后，再点击“Write To Flash”（写入闪存），随后等待烧录完成，完成后日志中出现“soft reset MCU”之后价签会自动刷新进入新固件工作，如果没动静请先尝试用手机搜索蓝牙，如果蓝牙也找不到设备说明要么当时短接时操作失误写入失败，要么你是用错了@和不带@版本的固件导致死机。

自动方案：直接NRST接到RTS，不用操作短接，其余和手动一样

烧录完成后可以使用对应固件的网页管理工具来初始化时间和更改内容。
